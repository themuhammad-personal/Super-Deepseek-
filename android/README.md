# Better DeepSeek Android

This directory contains the native Android host app for Better DeepSeek — the
only delivery target for the project. The app loads `chat.deepseek.com` in a
WebView and injects the Better DeepSeek bundle built for this target
(`assets/bds/`).

The canonical build and release notes live in the root [README.md](../README.md).

## Quick start

1. Build and stage the web assets from the repo root:

```bash
npm run build:android
```

2. Build the debug APK from this directory (the wrapper JAR is fetched on
   demand if missing):

```bash
./gradlew assembleDebug
# or, from the repo root (handles the wrapper for you):
npm run android:assemble:debug
```

The APK is written to `app/build/outputs/apk/debug/app-debug.apk`.

## Notes

- `app/src/main/assets/bds/` is generated by `npm run build:android`
  (git-ignored; never edit by hand).
- `MainActivity.kt` owns the WebView shell and injection lifecycle.
- `WebViewBridge.kt` exposes the `window.AndroidBridge` native surface consumed
  by `src/platform/android-bridge-shim.js` / `android-chrome-polyfill.js`.
- `McpClient.kt`, `YouTubeTranscript.kt`, `RemoteDataSync.kt` and
  `HarnessClient.kt` implement natively the message handlers that used to run
  in the browser extension's background service worker.
- Kotlin unit tests: `./gradlew test` (or `npm run android:test` from the root).
