# Super DeepSeek 2.70.0: ফোনে টেস্ট করার গাইড

প্রতিটা টেস্টে চারটা জিনিস আছে: **কোথায়**, **প্রম্পট (কপি-পেস্ট করুন)**, **পাস হলে কী দেখবেন**, আর **ফেল হলে কী লিখে জানাবেন**।

টেস্ট দুই রকম:

* **অংশ ক–খ (স্বাভাবিক প্রম্পট):** মডেল নিজে ঠিক করে UI বানাবে কিনা। একই সাথে রেন্ডারারও পরীক্ষা হয়। মডেল সবসময় নিয়ম মানে না, তাই কোনো উত্তরে UI না এলে আরেকবার **Regenerate** করুন। প্রতি ৫ বারে কতবার ঠিক এলো, সেটা লিখে রাখলেই সেটা হবে আসল compliance সংখ্যা।
* **অংশ গ–ঘ (হুবহু ব্লক):** এখানে মডেলকে একটা তৈরি ব্লক হুবহু লিখতে বলা হয়। তাই মডেলের বুদ্ধির উপর নির্ভর না করেই **অ্যাপের রেন্ডারার আর নিরাপত্তা** সরাসরি পরীক্ষা হয়। মডেল ব্লকটা বদলে ফেললে Regenerate করুন।

> আপনার নিজের মেসেজ বাবলে কোড ব্লক রেন্ডার হয় না। শুধু মডেলের উত্তরে হয়। এটাই প্রত্যাশিত।

## ০. প্রস্তুতি (একবার)

1. APK install করুন। 2.50 থাকলে তার উপরেই আপডেট হবে, লগইন থাকবে।
2. **Settings → Linux & Agent → Generative UI** খুলুন:
   * "জেনারেটিভ UI" চালু রাখুন।
   * "অনুরোধে নির্দেশনা যোগ" চালু রাখুন।
   * "কত ঘন ঘন" = **অটো**।
   * **ডায়াগনস্টিক চালান** চাপুন। ফলাফলে `modules`-এর ভেতরে `frame`, `viewer`, `inline`, `mcp` সব `true` হওয়া উচিত।
   * ✗ কোনোটা `false` হলে **রিপোর্ট কপি** চেপে আমাকে পাঠান।
3. প্রতিটা অংশ **নতুন চ্যাটে** শুরু করুন।
4. টেস্ট একবার light মোডে আর একবার dark মোডে করুন।

## ক. মেসেজের ভেতরে UI (ChatGPT-এর মতো)

### ক১: ধাপে ধাপে ডায়াগ্রাম
**প্রম্পট:**
```
DNS কীভাবে কাজ করে, ধাপে ধাপে ভিজুয়ালি ব্যাখ্যা করো।
```
**পাস:**
* উত্তরের লেখার মাঝেই একটা ডায়াগ্রাম আসে, ছবির মতো। চারপাশে কার্ডের বর্ডার থাকে না।
* লেখা আসার সাথে সাথে ডায়াগ্রামও আঁকা হতে থাকে।
* উচ্চতা নিজে থেকে মিলে যায়, ভেতরে আলাদা scrollbar থাকে না।
* নিচে ছোট আইকনের সারি থাকে: Expand, Copy, Download, Save, Show code।
* Dark মোডে রং বদলে যায়।

**ফেল হলে লিখবেন:** কিছুই আসেনি / শুধু কোড দেখাচ্ছে / খালি জায়গা / কেটে গেছে / "could not start here" এসেছে।

### ক২: চার্ট (বাইরের লাইব্রেরি, CSP পরীক্ষা)
**প্রম্পট:**
```
গত ১০ বছরে বাংলাদেশের জিডিপি প্রবৃদ্ধির হার একটা ইন্টারঅ্যাকটিভ চার্টে দেখাও।
```
**পাস (দুই রকম ফলের যেকোনোটা):**
* (ক) চার্ট মেসেজের ভেতরেই আসে, আর বারে ট্যাপ করলে মান দেখায়।
* (খ) "এখানে চালানো যায়নি" আসে, সাথে **Open full screen** বোতাম। সেটা চাপলে চার্ট পুরো স্ক্রিনে চলে।

**জানাবেন কোনটা হলো, (ক) না (খ)।** এই একটা তথ্য দিয়েই DeepSeek সাইটের CSP-র অজানা প্রশ্নের উত্তর মিলবে। (খ) হলে সেটা বাগ না, পরিকল্পিত fallback।

### ক৩: ক্যালকুলেটর/উইজেট
**প্রম্পট:**
```
২০ লাখ টাকা লোন, ৯% সুদ, ১৫ বছর। একটা EMI ক্যালকুলেটর বানাও যেখানে স্লাইডার দিয়ে মান বদলানো যায়।
```
**পাস:** মেসেজের ভেতরে স্লাইডার/ইনপুট আসে। মান বদলালে EMI সাথে সাথে বদলায়, আর পেজ পাশে সরে যায় না।

### ক৪: ভিজ্যুয়াল থেকে চ্যাটে প্রশ্ন পাঠানো
**প্রম্পট:**
```
সৌরজগতের গ্রহগুলোর একটা ইন্টারঅ্যাকটিভ ডায়াগ্রাম বানাও। কোনো গ্রহে ট্যাপ করলে sendPrompt দিয়ে আমার হয়ে সেই গ্রহ সম্পর্কে একটা প্রশ্ন পাঠাবে।
```
**পাস:** একটা গ্রহে ট্যাপ করলে চ্যাটে নতুন প্রশ্ন চলে যায়। এক মিনিটে ৪ বারের বেশি হলে অ্যাপ নিশ্চিতকরণ চায়।

### ক৫: সাধারণ প্রশ্নে UI আসা উচিত নয়
**প্রম্পট:**
```
বাংলাদেশের রাজধানীর নাম কী?
```
**পাস:** শুধু সাধারণ লেখা আসে, কোনো ভিজ্যুয়াল বা কার্ড আসে না।

### ক৬: Expand আর Save
ক১-এর ডায়াগ্রামের নিচে **Expand** চাপুন।

**পাস:**
* viewer পুরো স্ক্রিনে খোলে।
* ফোনের **Back** চাপলে বন্ধ হয়, অ্যাপ থেকে বেরিয়ে যায় না।
* **Save** চাপলে Settings → Generative UI → আর্টিফ্যাক্ট তালিকায় সেটা দেখা যায়।

## খ. আর্টিফ্যাক্ট (Claude-এর মতো)

একই চ্যাটে খ১ → খ২ পরপর করুন।

### খ১: গেম (html-app)
**প্রম্পট:**
```
ফোনে টাচ দিয়ে খেলা যায় এমন একটা Snake গেম বানাও।
```
**পাস:**
* লেখার সময় একটা ছোট কার্ড দেখায়: আইকন, শিরোনাম, স্পিনার আর "Generating…"।
* এ সময় কার্ডে ট্যাপ করলে Code ট্যাবে কোড লাইভ লেখা হতে দেখা যায়।
* লেখা শেষ হলে কার্ডে ধরন (যেমন "Interactive artifact · HTML") আর ডাউনলোড বোতাম দেখায়। একাধিক ভার্সন হলে ভার্সন নম্বরও দেখায়।
* ট্যাপ করলে viewer খোলে। উপরে আছে Close, শিরোনাম, **Preview | Code**, Copy আর ⋯ মেনু।
* গেম খেলা যায়।
* Back চাপলে viewer বন্ধ হয়।

### খ২: নতুন ভার্সন
**প্রম্পট (একই চ্যাটে):**
```
সাপের রং সবুজ করো আর স্কোর বড় করে উপরে দেখাও।
```
**পাস:**
* নতুন কার্ডে **v2** দেখায়।
* viewer-এ শিরোনামের পাশের "· v2" চাপলে ভার্সনের তালিকা আসে। v1 বেছে নিলে আগের গেম দেখায়।

### খ৩: ⋯ মেনুর প্রতিটা অপশন (খ১-এর viewer-এ)
| অপশন | পাস হলে |
|---|---|
| Copy | কোড ক্লিপবোর্ডে কপি হয় |
| Download | `.html` ফাইল Downloads-এ যায় |
| Share | Android-এর share sheet খোলে |
| Open in full screen | আলাদা স্ক্রিনে Claude-স্টাইল header-সহ অ্যাপ চলে, আর সেখানে Preview/Code, re-run, share কাজ করে |
| Re-run | গেম শুরু থেকে আবার চলে |
| Edit with AI… | লেখার বাক্সে ওই আর্টিফ্যাক্ট নিয়ে একটা অনুরোধ লেখা হয়ে যায় |
| Generative UI settings | সেটিংস খোলে |

### খ৪: React
**প্রম্পট:**
```
React আর Tailwind দিয়ে একটা টু-ডু অ্যাপ বানাও, আর্টিফ্যাক্ট হিসেবে দাও।
```
**পাস:** কার্ডে React ধরন দেখায়। Preview-তে অ্যাপ চলে, কাজ যোগ বা মুছে ফেলা যায়।
এটার জন্য esm.sh থেকে লাইব্রেরি লোড করতে হয়। তাই ক২-এর মতো "এখানে চালানো যায়নি" আসতে পারে, তখন Open full screen দিয়ে দেখুন।

### খ৫: ডকুমেন্ট
**প্রম্পট:**
```
একটা সফটওয়্যার কোম্পানিতে চাকরির আবেদনপত্র বাংলায় লিখে আর্টিফ্যাক্ট (document) হিসেবে দাও।
```
**পাস:** কার্ডে document ধরন দেখায়। Preview-তে সুন্দর ফরম্যাটে লেখা আসে, আর Download দিলে `.md` ফাইল নামে।

### খ৬: কোড
**প্রম্পট:**
```
Python-এ একটা ওয়েব স্ক্র্যাপার লিখে code আর্টিফ্যাক্ট হিসেবে দাও।
```
**পাস:** লাইন নম্বর আর রঙিন হাইলাইটসহ কোড দেখায়। Download দিলে `.py` ফাইল নামে।

### খ৭: Mermaid
**প্রম্পট:**
```
অনলাইনে অর্ডার দেওয়া থেকে ডেলিভারি পর্যন্ত পুরো প্রবাহ একটা Mermaid ডায়াগ্রাম আর্টিফ্যাক্টে দেখাও।
```
**পাস:** কার্ড খুললে ফ্লোচার্ট দেখায়।

### খ৮: SVG আর PNG
**প্রম্পট:**
```
"চা-ঘর" নামের একটা কফি শপের লোগো SVG-তে আঁকো, আর্টিফ্যাক্ট হিসেবে দাও।
```
**পাস:** লোগো দেখায়। ⋯ মেনুতে **Download as PNG** চাপলে ছবি সেভ হয়।

### খ৯: অ্যাপ বন্ধ করে খোলা
অ্যাপটা পুরো বন্ধ করুন (recent apps থেকে সরিয়ে দিন), তারপর আবার খুলুন।

**পাস:** Settings → Generative UI → আর্টিফ্যাক্ট তালিকায় খ১–খ৮ থাকে। **খুলুন** চাপলে ভার্সনসহ খোলে।

### খ১০: পাশের প্যানেল (ঐচ্ছিক)
ট্যাবলেট, ফোল্ড ফোন বা DeX-এ চওড়া স্ক্রিনে (৯৬০px বা বেশি) একটা আর্টিফ্যাক্ট খুলুন।

**পাস:** viewer ডানদিকে প্যানেলে খোলে আর চ্যাট বাঁদিকে সরে যায়।

## গ. হুবহু ব্লক: রেন্ডারার পরীক্ষা

প্রতিটা প্রম্পট পুরোটা কপি করুন, ভেতরের কোড ব্লকসহ।

### গ১: inline visual (নিশ্চিতভাবে)
~~~~
নিচের কোড ব্লকটা কোনো পরিবর্তন ছাড়া হুবহু তোমার উত্তরে লেখো, আগে-পরে এক লাইনের বেশি কিছু লিখবে না:

```sds-visual
title: তিন ধাপের প্রক্রিয়া
<svg viewBox="0 0 400 120" width="100%">
<rect class="box c-blue" x="10" y="35" width="100" height="50" rx="8"/><text class="th" x="60" y="65" text-anchor="middle">অনুরোধ</text>
<line class="arr" x1="110" y1="60" x2="150" y2="60"/>
<rect class="box c-green" x="150" y="35" width="100" height="50" rx="8"/><text class="th" x="200" y="65" text-anchor="middle">প্রক্রিয়া</text>
<line class="arr" x1="250" y1="60" x2="290" y2="60"/>
<rect class="box c-amber" x="290" y="35" width="100" height="50" rx="8"/><text class="th" x="340" y="65" text-anchor="middle">ফলাফল</text>
</svg>
```
~~~~
**পাস:** তিনটা রঙিন বাক্স আর তীর মেসেজের ভেতরে দেখায়। Dark মোডে লেখা পড়া যায়।

### গ২: html-app আর্টিফ্যাক্ট (নিশ্চিতভাবে)
~~~~
নিচের কোড ব্লকটা কোনো পরিবর্তন ছাড়া হুবহু তোমার উত্তরে লেখো:

```sds-genui
id: tap-counter
kind: html-app
title: ট্যাপ কাউন্টার
---
<!doctype html><html><head><meta name="viewport" content="width=device-width"><style>body{font-family:system-ui;display:grid;place-items:center;min-height:90vh}button{font-size:22px;padding:14px 28px;border-radius:999px}</style></head>
<body><button id="b">ট্যাপ: 0</button><script>var n=0;b.onclick=function(){b.textContent='ট্যাপ: '+(++n)}</script></body></html>
```
~~~~
**পাস:** একটা কার্ড আসে, তাতে লেখা "ট্যাপ কাউন্টার / Interactive artifact · HTML"। খুললে বোতাম চাপলে সংখ্যা বাড়ে।

**ভার্সন পরীক্ষা:** একই চ্যাটে একই প্রম্পট দিন, কিন্তু `ট্যাপ:` বদলে `চাপ:` লিখুন। কার্ড **v2** হওয়া উচিত। হুবহু একই প্রম্পট আবার দিলে নতুন ভার্সন হবে না, কারণ একই কনটেন্ট দুবার জমা হয় না।

### গ৩: ভুল ব্লকে অ্যাপ ক্র্যাশ করবে না
~~~~
নিচের কোড ব্লকটা হুবহু লেখো, তারপর এক লাইনে "শেষ" লেখো:

```sds-genui

```
~~~~

* কাঁচা কোড ব্লকটা দেখা যায়, সাথে কেন চালানো হয়নি তার ছোট নোট।
* কিছু চলে না।
* চ্যাট স্বাভাবিক থাকে, আর পরের মেসেজও ঠিকমতো রেন্ডার হয়।

### গ৪: সাধারণ ```html → কার্ড
~~~~


~~~~

এটা সেটিংসের "সাধারণ HTML / SVG রেন্ডার" অপশনের উপর নির্ভর করে। অপশনটা বন্ধ করলে সাধারণ কোড ব্লক থাকা উচিত।

### গ৫: সাধারণ ```svg → inline

## ঘ. নিরাপত্তা

### ঘ১: তৈরি করা কোড চ্যাট, কুকি বা native-এ ঢুকতে পারে কিনা
~~~~
নিচের কোড ব্লকটা কোনো পরিবর্তন ছাড়া হুবহু লেখো:

```sds-visual
title: নিরাপত্তা পরীক্ষা
<div class="card"><pre id="o">চলছে…</pre></div>
<script>
var r=[];
try{r.push('কুকি: '+(document.cookie===''?'খালি ✓':'পাওয়া গেছে ✗'))}catch(e){r.push('কুকি: ব্লক ✓')}
try{var x=parent.document.title;r.push('চ্যাট পেজ: ঢোকা গেছে ✗')}catch(e){r.push('চ্যাট পেজ: ব্লক ✓')}
r.push('origin: '+(self.origin==='null'?'আলাদা (null) ✓':self.origin+' ✗'));
try{var g=window.SdsBridgeGate;r.push('native: '+(!g?'নেই ✓':g.call('guess','getStorage','["x"]')))}catch(e){r.push('native: ব্লক ✓')}
fetch('https://example.com/').then(function(){r.push('নেটওয়ার্ক: খোলা ✗');show()},function(){r.push('নেটওয়ার্ক: ব্লক ✓');show()});
function show(){document.getElementById('o').textContent=r.join('\n')}
show();
</script>
```
~~~~
**পাস:** প্রতিটা লাইনে ✓ থাকে। native লাইনে `{"e":"denied"}` দেখালেও পাস।
**ফেল:** কোনো লাইনে ✗ এলে স্ক্রিনশট পাঠান। এটা সবচেয়ে গুরুত্বপূর্ণ টেস্ট।

যদি "এখানে চালানো যায়নি" আসে, তাহলে script মেসেজের ভেতরে চলতেই পারেনি। সেটাও নিরাপদ ফল, শুধু জানাবেন। full screen-এ এই পরীক্ষার ফল আলাদা হতে পারে, কারণ সেটা পুরো আলাদা WebView।

### ঘ২: export আর share-এ গোপন তথ্য মুছে যায় কিনা
~~~~
নিচের কোড ব্লকটা হুবহু লেখো:

```sds-genui
id: secret-test
kind: document
title: গোপন তথ্য পরীক্ষা

```
~~~~
কার্ড খুলুন, তারপর ⋯ → **Download** আর **Share** করুন।

**পাস:**
* নামানো বা শেয়ার করা ফাইলে key আর password-এর জায়গায় redacted চিহ্ন থাকে।
* "সাধারণ লেখা থাকবে।" ঠিকই থাকে।

### ঘ৩: অসীম লুপে চ্যাট আটকায় না
~~~~
নিচের কোড ব্লকটা হুবহু লেখো:


~~~~
**পাস:**
* সর্বোচ্চ ~২ সেকেন্ড চ্যাট একটু থেমে থাকতে পারে।
* তারপর ভিজ্যুয়ালের জায়গায় একটা ত্রুটির বার্তা আসে: "A loop ran for more than 2 s and was stopped…", সাথে **Fix** বোতাম।

**ফেল:** চ্যাট ৫ সেকেন্ডের বেশি আটকে থাকে, বা অ্যাপ force-close করতে হয়।

এই টেস্ট থেকেই 2.60.1-এর সুরক্ষাটা এসেছে। 2.60.0-তে এমন লুপে পুরো পেজ আটকে যেত, যা sandbox-এর Chromium-এ ধরা পড়েছিল।

## ছ. 2.70-এর নতুন টেস্ট

### ছ১: কাঁচা কোড একবারও দেখা যাবে না

**প্রম্পট:** `সৌরজগতের গ্রহগুলোর আকার তুলনা করে একটা ইন্টারেক্টিভ ভিজুয়াল দেখাও।`

**পাস:** উত্তর লেখার সময় কোডের বদলে প্রথমেই একটা হালকা ঝিকমিক করা বাক্স ("Creating visual") আসবে, তারপর সেই জায়গাতেই ভিজুয়াল। মাঝখানে কোনো কোড দেখা যাবে না, ব্লক লাফাবে না। এরপর চ্যাট বন্ধ করে আবার খুলুন: ভিজুয়াল সরাসরি আসবে, কোড আগে দেখাবে না।

**ফেল হলে লিখুন:** কোড কতক্ষণ দেখা গেল (প্রথমবার / পুরনো চ্যাটে), আর স্ক্রিনশট।

### ছ২: ভিজুয়াল থেকে ওয়েবের তথ্য

**প্রম্পট:** `open-meteo.com-এর API থেকে ঢাকার এখনকার তাপমাত্রা fetch করে একটা ছোট ওয়েদার কার্ড ভিজুয়াল বানাও।`

**পাস:** নিচে একটা শিট আসবে: "… wants to access api.open-meteo.com" — Deny / Allow once / Always allow। **Always allow** চাপলে কার্ডে আসল তাপমাত্রা দেখাবে। আবার একই রকম প্রশ্ন করলে আর জিজ্ঞাসা করবে না। *Generative UI settings → Web access from visuals*-এ সাইটটা দেখা যাবে, "Forget all sites" দিয়ে মুছতে পারবেন।

**ফেল হলে লিখুন:** শিট এসেছিল কিনা, কোন বোতাম চাপলেন, কার্ডে কী লেখা ছিল।

### ছ৩: যেকোনো ফাইল আপলোড

**কোথায়:** + → Upload file, আর DeepSeek-এর নিজের আপলোড বোতাম — দুটোতেই।

**ফাইল:** একটা `.odt` বা `.epub`, একটা `.zip` (ভেতরে কিছু কোড/টেক্সট), একটা `.rtf`, আর একটা ভিডিও।

**পাস:** "Preparing files…" দেখিয়ে odt/epub/zip/rtf `নাম.txt` হিসেবে চ্যাটে যুক্ত হবে, মডেল ভেতরের লেখা পড়ে উত্তর দেবে। PDF/DOCX/ছবি আগের মতোই সরাসরি যাবে। ভিডিও যুক্ত হবে না, কারণসহ বার্তা দেখাবে।

**ফেল হলে লিখুন:** কোন ফাইল, কোন পথে (+ নাকি DeepSeek-এর বোতাম), কী বার্তা দেখাল।

### ছ৪: quran.ai MCP reader

**কোথায়:** MCP সার্ভারে `https://mcp.quran.ai` যোগ করুন।

**ফেল হলে লিখুন:** টুল কার্ড এসেছিল কিনা, রিডারের জায়গায় কী দেখা গেল, স্ক্রিনশট।
