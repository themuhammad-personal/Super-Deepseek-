# Archive

Historical notes from the earlier **React SPA / direct-API** design, where the app
talked to `/api/v0` itself (proof-of-work, SSE parsing, token handling).

That design was replaced: the official DeepSeek site is now the chat surface and the
Super DeepSeek engine is injected on top of it. See [`../ARCHITECTURE.md`](../ARCHITECTURE.md).

These files are kept for reference only and do not describe the shipping app.
